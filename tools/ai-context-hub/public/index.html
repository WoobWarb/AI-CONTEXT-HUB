🌐 วิธีเชื่อมต่อเครื่องเข้ากับ ChatGPT Custom Actions

คุณสามารถให้ ChatGPT สั่งอ่านและแก้ไขไฟล์ในโฟลเดอร์นี้ได้โดยตรงผ่าน Tunnel:

# 1. รันคำสั่งเปิด Tunnel ในเทอร์มินัล
npx cloudflared tunnel --url http://localhost:4001

2. คุณจะได้ URL เช่น https://your-tunnel.trycloudflare.com

3. ใน ChatGPT ไปที่ Explore GPTs -> Create -> Configure -> Actions

4. ในช่อง Schema ให้กรอก URL หรือเนื้อหาจาก:

http://localhost:4001/openapi.json

5. บันทึก Action เพียงเท่านี้ AI บนหน้าเว็บจะสามารถเข้าถึงและแก้ไขไฟล์ในเครื่องของคุณได้ตามสั่ง!

⭐ วิธีที่ 1: ติดตั้งเป็น Chrome Extension (แนะนำ เสถียร 100%)

ติดตั้ง Extension เพียงครั้งเดียว AI Hub จะเชื่อมกับแท็บแชทโดยอัตโนมัติ ส่งข้อความได้ทันที และให้ AI อ่าน/สร้างไฟล์ในเครื่องได้:

1 เปิดแท็บใหม่ใน Chrome แล้วพิมพ์: chrome://extensions
2 เปิดสวิตช์ "โหมดนักพัฒนา" (Developer mode) ที่มุมขวาบนของหน้าจอ
3 กดปุ่ม "โหลดส่วนขยายที่คลายการบีบอัดแล้ว" (Load unpacked) ที่มุมซ้ายบน แล้วเลือกโฟลเดอร์ extension:

* หลังจากติดตั้งเสร็จ ให้เปิดหรือรีเฟรชหน้า ChatGPT / Claude / Gemini จะมีกล่อง AI Hub โผล่ขึ้นมาที่มุมขวาล่างทันทีครับ!
